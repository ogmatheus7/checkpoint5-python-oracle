# Checkpoint 5 - Previsão do tempo com Python e Oracle

Projeto de Computational Thinking using Python (Prof. Fernando Almeida).

O programa consulta a previsão de 7 dias de 4 cidades (São Paulo, Rio de Janeiro, Curitiba e Manaus) na API pública Open-Meteo, calcula a temperatura média e a amplitude térmica, classifica o dia e a chuva, e grava os resultados em uma tabela do Oracle da FIAP.

## Como rodar

1. Instale as dependências: `pip install requests oracledb`
2. Execute: `python checkpoint5.py`
3. Digite o usuário e a senha do Oracle quando o programa pedir.
